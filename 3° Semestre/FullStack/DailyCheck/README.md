# 📋 Daily Check

Projeto simples de gerenciamento de tarefas com consulta de clima.

---

## 🚀 Funcionalidades

- Criar tarefas
- Listar tarefas na Home
- Excluir tarefas
- Consultar clima por cidade
- Integração com API OpenWeather

---

## 🧠 Tecnologias

Frontend:
- HTML
- CSS
- JavaScript

Backend:
- Node.js
- Express
- Prisma


---

## ⚙️ Como rodar o projeto

### 1. Instalar dependências

cd api

npm install

---

### 2. Configurar banco (Prisma)

npx prisma generate

npx prisma db push

---

### 3. Rodar backend

node server.js


---

### 4. Rodar frontend

Abra o arquivo:
index.html

ou use Live Server no VS Code.

---

## 🌦️ API de clima

OpenWeather API:
https://home.openweathermap.org/api_keys

---

## 📌 Observações

- O backend precisa estar rodando para o sistema funcionar
- Prisma gerencia o banco de dados
- As tarefas aparecem automaticamente na Home
